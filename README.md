Почему экономия экономна а производительность производительна

Ультра-экономия:

<br> Сеть / батарея
<br>Мин. CPU	0 / 0
<br>Макс. CPU	50 / 10
<br>Охлаждение	пассив / пассив
<br>Диск	2 мин / 1 мин
<br>ASPM	макс / макс
<br>USB	вкл / вкл
<br>Вайфай	сред / макс



Главный рычаг — кап 10% на батарее: процессор физически не может уйти выше десятой доли частоты, а потребляет он примерно как квадрат напряжения × частота, так что срез верха даёт львиную долю экономии. Пол 0% — в простое проц лежит на самом низком P-state. Пассивное охлаждение — вентиляторы вообще не крутятся, при нагреве проц сначала сбрасывает частоту (тихо, но медленнее). ASPM на максимуме усыпляет PCIe-линки видеокарты и SSD между пакетами, USB и вайфай спят при простое. Поэтому ютуб с аппаратным декодом идёт, а батарея тает медленно.



<br>Ультра-производительность:
<br>Сеть / батарея
<br>Мин. CPU	100 / 100
<br>Макс. CPU	100 / 100
<br>Охлаждение	акт / акт
<br>Диск	никогда
<br>ASPM	off / off
<br>USB	выкл / выкл
<br>Вайфай	макс / сред

Здесь убраны все микро-задержки, а не только подняты частоты. Пол и потолок 100% — проц всегда на максимуме, рамп-апа нет в принципе (именно он даёт микрофризы в играх при выходе из простоя). Активное охлаждение — при нагреве сначала летят вентиляторы, троттлинг самый последний. ASPM off — линки PCIe не спят, у GPU/SSD нет задержек на пробуждение. Диск никогда не паркуется, USB-девайсы всегда готовы (важно для геймпадов/ЦАПов без задержек опроса). Поэтому «производительна» — это отсутствие сна у каждого компонента.

<br>Баланс:
<br>Сеть / батарея
<br>Мин. CPU	50 / 30
<br>Макс. CPU	100 / 85
<br>Охлаждение	акт / акт
<br>Диск	20 мин / 10 мин
<br>ASPM	умерен. / умерен.
<br>USB	выкл / вкл
<br>Вайфай	мин / сред

Низ 30% на батарее — отклик без просадки в простое, пик 85% — почти весь буст для дел, но самый прожорливый верх срезан. Активное охлаждение держит sustained-нагрузку (компиляция, звонки) без раннего троттлинга. Остальное поделено по источнику: от сети комфорт, от батареи экономия.
